# Preferências do projeto
- Salvar alterações concluídas em commits e enviar a branch ao GitHub (origin), conforme pedido de Joao Carlos Campos.
- Nunca incluir .env, credenciais, chaves, dumps ou dados pessoais nos commits.
- Antes de mudanças extensas, criar checkpoint. Validar build, testes e fluxos afetados.
- Distinguir funcionalidades disponíveis de integrações futuras. Não apresentar pagamentos simulados como cobranças reais.
